# 挂载外部硬盘操作步骤

## 1. 查看磁盘信息
- 使用 `sudo fdisk -l` 命令列出系统中所有磁盘及其分区信息
- 找到新的 512GB 磁盘 `/dev/vdb`

## 2. 创建分区
使用 `sudo fdisk /dev/vdb` 对新磁盘进行分区：

1. 输入 `n` 命令创建新分区
2. 输入 `p` 创建主分区
3. 输入 `1` 设置为第一个分区
4. 按回车使用默认起始扇区 (2048)
5. 按回车使用默认结束扇区 (全部空间)
6. 输入 `w` 保存更改并退出

注意：
- 可输入 `m` 查看帮助信息
- 可输入 `q` 退出不保存更改
- 建议先用 `p` 命令查看当前分区表

## 3. 格式化分区
- `sudo mkfs.ext4 /dev/vdb1`
- 将新分区格式化为 ext4 文件系统
- 设置 UUID 和超级块备份

## 4. 创建挂载点
- `sudo mkdir -p /data`
- 创建 `/data` 目录用于挂载新分区

## 5. 挂载分区
- `sudo mount /dev/vdb1 /data`
- 将新分区挂载到 `/data` 目录

## 6. 配置自动挂载
- `sudo sh -c 'echo /dev/vdb1 /data ext4 errors=remount-ro 0 1 >> /etc/fstab'`
- 将挂载信息添加到 `/etc/fstab`
- 设置 errors=remount-ro 参数 (错误时以只读方式重新挂载)

## 7. 验证挂载配置
- `sudo findmnt /data --verify --verbose`
- 检查目标目录、文件系统选项等配置是否正确

## 8. 设置目录权限
- `sudo chown ${USER} /data`
- 将 `/data` 目录所有权更改为当前用户

## 9. 创建符号链接
- `ln -s /data ~/data`
- 在用户主目录下创建指向 `/data` 的符号链接

## 10. 验证磁盘空间
- `df -h`
- 显示挂载点的磁盘使用情况
- 总空间约 527GB，已使用 28KB，可用空间约 500GB
